# Porto scientific model contract

This contract was fixed before constructing or running the baseline. The canonical input is Zenodo v4, DOI 10.5281/zenodo.20707207. README_v2.txt contains an older DOI in its header. The archive, README and generator were inspected as data/format evidence. [Zenodo v4](https://zenodo.org/records/20707207) · [Almeida et al., Data in Brief 67, 113063](https://pmc.ncbi.nlm.nih.gov/articles/PMC13396958/)

| Classification | Contract |
|---|---|
| Published format | Header gives K, N, counts of physical origin and destination depots, physical stations, visit allowance per station and horizon in minutes. Requests pair IDs i and N+i. Nodes carry WGS84 latitude/longitude, service minutes, integer load change and inclusive service-start windows. For the published cases, the depot block holds two common IDs and K dedicated IDs in each direction. Station IDs name physical LEC sites. Matrix row/column ID i maps to index i−1, with no symmetrization. |
| Published constraints | Each listed vehicle has one route, uses its own assigned depots and returns empty. Each pair is served once in order on a single vehicle. On-board minutes equal dropoff service start minus pickup service completion. Excess subtracts direct matrix minutes, per the paper's equation. Passenger occupancy changes at pickup completion and dropoff service start. Waiting may occur before service or after a stop. Finish by the horizon. |
| Published energy | Use raw file values. The smallest file starts each vehicle at 40.25 kWh with 57.5 kWh capacity and a 0.70 final ratio. Consume 0.09 kWh per matrix travel minute. Battery must remain within bounds before and after charging and meet the destination reserve. The actual station rate is 22/60 kWh/min, printed as 0.36666666666666664, versus the rounded 0.367 in the paper. The 96 tariff and surplus intervals are 15 minutes. |
| Derived quantities | Arc kWh = matrix minutes × consumption rate. A charging event has constant kWh/min and uses each half-open interval in proportion to time actually spent charging in it. Fleet LEC energy in a station-period is min(demand, available surplus) and remainder is grid energy. |
| Explicit modeling assumptions | Honor each station's rate per active charging vehicle. The sources do not provide a simultaneous outlet count or an unambiguous aggregate power constraint. Share the finite station-period surplus pro rata by kWh for reporting, with no carryover. Treat the provided MMR series as the LEC price as in the paper's dispatch paragraph. Its tariff-construction paragraph also describes an effective blended price, so an independent published cost comparison remains blocked pending clarification. |
| Explicit modeling assumptions | Only empty vehicles may visit a charging station. Enforce the header's visit cap per physical station across the fleet and use each station-copy node at most once across the fleet. The release has one visit and no extra copies. The 2026 description leaves the visit scope and on-board charging implicit. This conservative reading follows §3.1 of the directly related e-ADARP formulation by three dataset authors. Charge after station service, with optional explicit pre-charge waiting. For a compatible future extension accept only complete groups of copies that uniquely match a physical station's coordinates. [Bresich, Raidl and Limmer (2024)](https://www.honda-ri.de/pubs/pdf/5818.pdf) |
| Published coefficients and frozen monetary interpretation | Travel cost = 0.36 EUR/min × travel minutes. User cost = 0.31 EUR/min × excess ride minutes. Pilot objective = travel cost + user cost + charging cost. The 0.75 / 0.25 coefficients belong to the legacy time-only objective and are preserved separately. No additional monetary weights are inferred. The paper provides no solved optima for this set. |

The evaluator uses absolute feasibility tolerances of 1e-7 in minutes, kWh and kWh/min for floating-point roundoff. IDs and passenger counts are exact. The benchmark uses published matrix travel times and source energy profiles. Taxi origins and destinations informed the instances, while the demand windows, charging sites and community scenarios are benchmark constructions.
